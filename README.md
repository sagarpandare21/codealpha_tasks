## Task 1: Hangman Game

### Description
A simple text-based Hangman game developed using Python.

The player has to guess the hidden word one letter at a time. The game randomly selects a word from a list of five predefined words.

### Features
- Uses 5 predefined words
- Randomly selects a word
- Player guesses one letter at a time
- Maximum 6 incorrect guesses
- Displays correctly guessed letters
- Shows a Game Over message when all attempts are used
- Console-based interface

### Technologies Used
- Python
- Random module
- Lists
- Strings
- While loop
- For loop
- If-else statements
